# 📞 SCRIPTS DE ABORDAGEM

## Abordagem por Telefone/WhatsApp

---

### Primeiros 30 segundos (Gancho):

```
"Olá [Nome], tudo bem?

Eu sou [seu nome] da AgroLink. A gente desenvolveu uma tecnologia 
que ajuda cooperativas a reduzir inadimplência no crédito rural 
usando dados reais de produção dos produtores.

Você teria 5 minutos pra eu te explicar como funciona?"
```

---

### Se disser SIM (Explicação rápida):

```
"É o seguinte: a gente percebeu que muita cooperativa libera 
crédito sem saber direito se o produtor realmente vai conseguir 
pagar, porque depende de papelada antiga.

O que a gente faz é: o produtor que já usa nossos sistemas 
(AgrOS e AgroCore) gera automaticamente dados de produção real — 
área plantada, produtividade, custos, pagamentos.

Com isso, a gente calcula um score de crédito específico pro agro, 
de 0 a 1000. Quanto maior, menor o risco pra vocês.

A grande vantagem: vocês conseguem liberar mais crédito pros 
produtores bons, com menos risco, e ainda reduzem inadimplência.

E pra cooperativa, é de graça no começo — a gente só cobra quando 
começa a usar de verdade."

---

### Se perguntar "como funciona na prática?":

```
"Na prática é simples:

1. A gente manda pra vocês uma lista dos produtores que já 
   têm score alto — acima de 750, por exemplo. Esses são os 
   que tem menor risco de inadimplência.

2. Vocês selecionam quem querem oferecer crédito.

3. A gente mostra o score, o histórico, e vocês decidem.

4. Se liberarem, a gente acompanha o comportamento — 
   se o cara paga em dia, o score sobe; se atrasa, cai.

5. Mensalmente a gente manda um relatório de como tá 
   a carteira de vocês."
```

---

```

Se quiser, posso te mandar um vídeo de 3 minutos mostrando 
como funciona, e você avalia com calma. Sem pressão.

Posso mandar?"
```

## Checklist de Prospecção

### Antes da ligação:
- [ ] Pesquisar a cooperativa no site e redes sociais
- [ ] Verificar tamanho (quantos cooperados)
- [ ] Identificar o nome do responsável por crédito
- [ ] Preparar argumentos com dados reais
- [ ] Ter o material pronto pra enviar

### Durante a ligação:
- [ ] Apresentação curta e direta (2-3 min máx)
- [ ] Perguntar se é um bom momento
- [ ] Focar no problema (inadimplência)
- [ ] Oferecer teste gratuito
- [ ] Confirmar dados de contato
- [ ] Agendar próxima conversa

### Após a ligação:
- [ ] Enviar material em até 2 horas
- [ ] Mandar mensagem no WhatsApp thanking
- [ ] Registrar tudo no CRM/seu sistema
- [ ] Agendar follow-up para 3-5 dias depois
